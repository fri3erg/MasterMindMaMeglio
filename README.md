# MasterMindMaMeglio Mathematica - Gioco con Quiz Integrato

Un clone del classico gioco di decifratura **MasterMind**, sviluppato in *Wolfram Mathematica*, con meccaniche ispirate a Wordle e un sistema di suggerimenti basato su quiz di cultura generale.

Sviluppato come progetto di Matematica Computazionale per l'Università di Bologna, Laurea Magistrale in Informatica, a.2024/2025

## Come Funziona

- **Gioco Base**: Indovina la sequenza di colori segreta entro un numero limitato di tentativi.
- **Feedback**: I pioli laterali indicano:
  - (verde) **Esatto**: Colore corretto e posizione giusta.
  - (giallo) **Spostato**: Colore corretto ma posizione sbagliata.
  - (vuoto) **Assente**: Colore non presente nella sequenza.
- **Quiz Bonus**: Rispondi a domande di trivia per ottenere suggerimenti!
